# ROADMAP — 产品演进项排期

> 权威来源：本文件是演进项排期的唯一规划入口；各项口径细节以 DECISIONS.md 对应条目为准，此处只保留排序与启动条件。
> 最后更新：2026-09-17（排期拍板）

## 排期原则

- **数据门槛决定顺序**：多数演进项被「MVP 上线后积累运营数据」卡住，系统真机运行前不排第二、三档开发。
- **绑定项不拆**：标题脚本一致性检查 ⊂ LLM composer；多版本产出 ⊂ LLM composer，作为同一演进包推进。
- **门槛项单列**：依赖外部资质/基建的项与工程排期解耦跟踪。

## 第二档 · 观察期后按数据复盘（质量与合规增强）

先跑一段、看真实 BLOCKED/重复率再决定投入：

- 署名「素材级剔除」（D12）— 按实际 BLOCKED 率复盘，误杀高才做。
- 质量分按形态分公式调权（D12）— 需运营数据校准权重（错位记入 RISKS.md）。
- 重复事件/相似脚本/重复镜头检测（D12）— 防重复发布，规模化后价值上升。
- 风险标签 + 待确认队列（D12）— 特殊事件人工兜底。

## 第三档 · 长期（智能与自动化，强依赖前序数据/外部条件）

- LLM composer + 标题脚本一致性检查（D12，绑定项）— 协议已预留（D9）；一致性检查仅在 LLM 生成后有意义。
- 多版本产出：快讯/解读/垂直版（§4.4，D12）— 依赖 LLM composer。
- 数据回流自动调参（D3/§7）— 需回流数据积累；单次调幅 ≤15%、观察期 7 天、一键回滚、仅当前账号生效。
- 表现数据自动采集（D15）— 需数据页 RPA 校准或平台开放能力。

## 第四档 · 门槛项（外部资质/基建，非纯排期可控）

- MCN/企业资质 → 头条官方 API 适配器替代 RPA（§7，D5）— 卡在资质获取，单独跟踪。
- 统一后台：授权/评分/账号画像（§7）— 基建级，多版本/垂类分类就绪后合并。

## 明确不做（除非前提变化）

- 引用比例超限检查（D9）— 素材无原文可比对，属假检查，维持不实现。
