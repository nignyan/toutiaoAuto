# 重生产能力 设计文档

> 日期：2026-09-17 ｜ 来源：ROADMAP 第一档第 1 项（D12 遗留演进项）｜ 状态：设计已确认，待实现
> 决策背景：D12 曾拍板「READY→PRODUCED 一次性，素材晚到/授权补录对已 PRODUCED 事件无效」为有意取舍；本设计推翻该取舍，提供成品级重产能力。

## 1. 需求与拍板结论

运营痛点：事件已生产成品后，素材晚到或授权补录解锁，旧成品内容基于过时素材（或因素材不齐质检 HELD 留档），需要用事件当前素材重新生成内容。

用户逐题拍板（2026-09-17）：

| 决策点 | 拍板 |
|---|---|
| 重产触发范围 | 所有未发布成品（HELD / 未入队 QUALIFIED / 队列 pending / failed / skipped） |
| 旧成品处置 | 原地覆盖（同一成品行内容字段覆盖，质检重算，事件保持 PRODUCED） |
| draft_ready 处理 | 阻塞重产（409），避免孤儿草稿 |
| 方案 | 方案 A：成品级 reproduce 端点（否决放开 produce 守卫 / 事件回 READY 两个方案） |

## 2. 编排层设计（app/pipeline/producer.py）

新增 `reproduce_for_production(db, production_id, composer=None) -> Production`：

1. `ProductionDao.get(production_id)` → 无则 `ProducerError("not_found")`。
2. `PublishQueueDao.get_by_production(production_id)` → 状态为 `draft_ready` 或 `published` 则 `ProducerError("queue_state")`。
3. `EventDao.get(prod.event_id)` → 无则 `not_found`（理论不发生）；`MediaAssetDao.list_by_event` 取当前素材实时复跑 `decide_format` → DEFER 则 `ProducerError("not_ready")`。
4. 复用现有生产核心（`composer.compose` + `check_quality` + 素材 id 一致性防御检查），结果写回同一成品行。
5. 覆盖字段：`production_type / asset_ids / title / body / cover_asset_id / rule / composer / checks / vetoes / quality_score / quality_status`。不动字段：`id / event_id / account_id / created_at / vertical`。
6. 单表更新，无跨表原子需求，不使用 `db.transaction()`（遵守 DB 锁不可重入约束）；`ProductionDao` 新增 `update_content` 方法。

不变量：

- 事件全程保持 PRODUCED，事件状态机零改动。
- 队列 1:1（UNIQUE(production_id)）天然保持，队列项 pending/failed/skipped 原状态不动，派发时自然使用新内容。
- 回流按 production_id 记账不断链。
- 重复重产幂等可再跑（每次以事件当前素材重新覆盖）。

## 3. API 设计（app/api/pipeline.py）

`POST /productions/{production_id}/reproduce`

- 200：返回更新后的成品。
- 404：`not_found`（成品不存在）。
- 409：`queue_state`（队列项 draft_ready / published）或 `not_ready`（形态判定 DEFER）。
- 批量 reproduce 不做（YAGNI）。

## 4. 已知语义取舍

- 旧稿内容不可追溯：原地覆盖的代价，拍板接受。
- 队列行内手改标题（PATCH /publish-queue/{id} title 落到 production.title）会被重产新标题覆盖——新内容配新题，预期行为。
- draft_ready 永久阻塞重产：运营需先走完发布（confirm）或放弃该草稿；无 draft_ready → pending 回退通道（维持现有状态机）。
- 重产后质检仍 HELD：继续「留档 + 人工捞回」，与 D12 现有语义一致。
- 头条草稿箱内可能残留的探针/废弃草稿由运营人工删除（既有口径，不在本设计范围）。

## 5. 测试计划

- HELD 成品 + 事件补录 usable 素材 → 重产：内容字段覆盖、质检重算、事件保持 PRODUCED。
- 未入队 QUALIFIED / 队列 pending / failed / skipped → 重产成功，队列项状态不变且跟随新内容。
- draft_ready → 409；published → 409；成品不存在 → 404；形态判定 DEFER → 409。
- 重复重产幂等；produce / produce_all 行为不受影响。
- DAO：`update_content` 覆盖内容字段且不动 id / event_id / account_id / created_at / vertical。
